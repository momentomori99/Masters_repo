============
Finally got 80%!
Changes Ive done:
changed the way input is connected to the reservoir. Each excitatory neuron receives input from only one input neuron. 
Some input neurons can be connected to multiple E neurons, but those E neurons cannot be connected to any other Input neurons
We still divide the input into bins of 50 ms
And also, have scaled up the input pixels by 5 times. This is equivelent of intensity of 320
